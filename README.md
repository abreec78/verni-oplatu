# Верни оплату

Тестовое PWA для учета неоплаченных услуг. Данные хранятся только в браузере (localStorage), без синхронизации и серверной базы. Не используйте как единственную копию реальных клиентских данных.

После загрузки файлов приложение можно опубликовать на HTTPS-хостинге. GitHub Pages для приватного репозитория зависит от тарифа и настроек. Публикация Pages делает сайт публичным.
